# Changelog

## 0.1.0

First ledger opened.

- Engine with data-driven feats: counters, tiers, sliding windows, streaks, per-session counters and an anti-cheese cooldown on chat keywords.
- 329 feats in ten packs, each pack toggleable.
- Signals for deaths, chat, emotes, interface habits, error messages, movement, vendors, mail, trade, quests, groups, guilds, time and class abilities. No combat data is read.
- Herald for guild and party chat with a one-line-per-minute throttle, burst summaries, an instance queue and merging of simultaneous announcements.
- Guild sync, leaderboard, weekly "most in debt" line and tooltip line.
- Whisper replies to `!dkp` and `!shame`.
- Ledger window, toast and minimap button.

Not yet tested in game. C-rated feats are off by default.
